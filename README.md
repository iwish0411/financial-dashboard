# 金融资产收益与风险分析平台

本项目基于 Python 和 Streamlit 开发，支持 Excel 上传，自动计算收益率、年化收益率、波动率、最大回撤、夏普比率、资产相关性和风险评级。

## 功能

- 支持演示数据
- 支持 Excel 上传
- 自动计算收益率与风险指标
- 绘制价格走势、收益率变化、回撤曲线
- 支持多资产对比
- 支持相关性矩阵
- 自动生成分析结论

## 技术栈

Python / Streamlit / Pandas / NumPy / Plotly / OpenPyXL

## 说明

本项目仅用于金融数据分析学习与展示，不构成任何投资建议。
